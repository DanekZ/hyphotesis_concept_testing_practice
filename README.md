# 🧪 Hypothesis Concept Testing Practice

A hands-on practice repository focused on **statistical hypothesis testing** using Python. This project includes a Jupyter Notebook assignment paired with a real dataset in Excel format, covering core concepts of hypothesis testing from theory to implementation.

---

## 📁 Repository Contents

| File | Description |
|------|-------------|
| `Assignment 13.ipynb` | Jupyter Notebook containing hypothesis testing exercises and solutions |
| `Assignment Hypothesis Testing.xlsx` | Dataset used for the analysis in the notebook |

---

## 📊 Topics Covered

- Null and alternative hypothesis formulation (H₀ and H₁)
- Significance level (α) and p-value interpretation
- One-sample and two-sample tests
- t-tests and z-tests
- Drawing statistical conclusions from test results

---

## 🛠️ Tools & Libraries

- **Python 3.x**
- **Jupyter Notebook**
- **pandas** — data loading and manipulation
- **NumPy** — numerical computations
- **SciPy** — statistical testing functions
- **openpyxl / xlrd** — reading Excel data files

---

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- Jupyter Notebook or JupyterLab

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/DanekZ/hyphotesis_concept_testing_practice.git
   cd hyphotesis_concept_testing_practice
   ```

2. Install required libraries:
   ```bash
   pip install pandas numpy scipy openpyxl jupyter
   ```

3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

4. Open `Assignment 13.ipynb` and run the cells.
